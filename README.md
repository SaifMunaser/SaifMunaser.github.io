OW Explorer — Overwatch Heroes & Maps
A web app built with HTML, Bootstrap, and Vanilla JavaScript that uses the OverFast API to browse Overwatch heroes and maps.
Pages

Heroes page — browse all heroes, filter by role, search by name
Maps page — browse all maps, filter by game mode, search by name
Map Detail page — click any map to see more info and a recommended hero

API Used

OverFast API — https://overfast-api.tekrop.fr
No API key required
Endpoint 1: /heroes — returns hero name, portrait, and role
Endpoint 2: /maps — returns map name, screenshot, location, and game modes

Libraries Used

Bootstrap 5 — for responsive layout and styling
Vanilla JavaScript — fetch(), async/await, DOM manipulation

How to Use

Open index.html to browse heroes
Use the search bar or role buttons to filter
Click Maps in the navbar to browse maps
Click any map card to see its details and a recommended hero
